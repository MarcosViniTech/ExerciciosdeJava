# ☕ Exercícios de Java

## 📌 Sobre o Repositório
Repositório destinado a reunir exercícios práticos de programação desenvolvidos durante os estudos de Java no segundo semestre, com foco na aplicação de conceitos fundamentais da linguagem e no desenvolvimento da lógica de programação.

## 💻 Exercícios Desenvolvidos
- **Cadastro Básico:** exercício de entrada e exibição de dados.
- **Cálculo Numérico:** operações e cálculos matemáticos.
- **Combustível:** cálculos relacionados ao consumo de combustível.
- **Conta de Luz:** cálculo de valores de consumo de energia.
- **Desconto Fixo:** aplicação de descontos em valores.
- **Pedido com Imposto Fixo:** cálculo de pedidos com impostos.
- **Pedido Simples:** operações básicas envolvendo pedidos.
- **Retângulo e Medidas:** cálculos de medidas geométricas.
- **Tempo de Viagem:** cálculo de duração de viagens.
- **Termômetro:** conversões e operações envolvendo temperatura.

## 🛠️ Tecnologia
- Java

## 🎯 Objetivo e Aprendizados
Praticar lógica de programação, variáveis, entrada e saída de dados, operadores matemáticos, cálculos e resolução de problemas utilizando Java.
